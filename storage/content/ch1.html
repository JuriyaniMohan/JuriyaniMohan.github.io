01 Storage Fundamentals

Cloud storage is the backbone of every modern application. Understanding the three fundamental storage types — Object, Block, and File — and knowing when to use each is the foundation of all cloud architecture decisions.

▸ Three Pillars of Cloud Storage

Object vs Block vs File — Deep Comparison

AspectObjectBlockFile
Access MethodREST API (HTTP)OS-level deviceNFS/SMB protocol
Data UnitObject (any size)Fixed blocks (512B–4KB)Files in directories
MetadataRich, custom key-valueMinimalStandard file attributes
ModifyReplace entire objectModify individual blocksModify bytes in-place
LatencyHigher (ms)Very low (sub-ms)Medium (ms)
ScalabilityVirtually unlimitedLimited to disk sizeGrows within limits
CostLowest per GBHighest per GBMedium per GB
Multi-accessYes (concurrent HTTP)Single VM (usually)Yes (multi-mount)

Real-World Use Case Mapping

WorkloadBest Storage TypeWhy

Data Lake / AnalyticsObjectMassive scale, columnar file formats (Parquet)
