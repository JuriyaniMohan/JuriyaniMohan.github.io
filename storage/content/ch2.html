Object Storage

Buckets & Containers

Object storage organizes data in buckets (AWS/GCP) or containers (Azure). A bucket is a globally unique namespace that holds objects.

  • Bucket names must be globally unique across all accounts (AWS S3, GCS). Azure container names only need to be unique within the storage account.
  • Region-bound: Buckets are created in a specific region. Data stays there unless you configure cross-region replication.
  • No nesting: You cannot create buckets inside buckets. Folders are simulated by key prefixes (e.g., logs/2025/jan/file.log).

Flat Namespace

Object storage uses a flat namespace — there are no real directories. What appears as a folder path like videos/2025/keynote.mp4 is actually just a key string. The "/" delimiter is a convention, not a filesystem structure.

GCS Hierarchical Namespace: Google Cloud offers an opt-in hierarchical namespace on GCS buckets (HNS buckets) which provides real directory semantics with atomic renames — useful for Hadoop/Spark workloads that rely on directory operations.

Versioning

When versioning is enabled, every overwrite or delete creates a new version rather than replacing the object. This protects against accidental deletion and overwrites.

  • Version ID: Each version gets a unique ID. You can retrieve or restore any version.
  • Delete markers: Deleting a versioned object creates a "delete marker" — the object appears deleted but previous versions remain.
  • Cost implication: All versions consume storage. Use lifecycle rules to expire old versions.
  • MFA Delete (AWS): Requires multi-factor authentication to permanently delete object versions — extra protection layer.

Static Website Hosting

Object storage can serve static websites directly without a web server. Configure an index document (e.g., index.html) and an error document (e.g., 404.html). Combined with a CDN (CloudFront, Azure CDN, Cloud CDN), this is the cheapest and most scalable way to host static sites.

// AWS S3 Static Website URL pattern: http://my-bucket.s3-website-us-east-1.amazonaws.com // Azure Static Website: https://myaccount.z13.web.core.windows.net // GCS: https://storage.googleapis.com/my-bucket/index.html
